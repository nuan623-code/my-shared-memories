Agent 技术精选

  • AgentPerfBench:agent 负载和聊天负载差一个数量级。H100 + LLaMA-3.1-70B 饱和时 TTFT 从 239 ms 涨到 1,139 ms;SWE-Bench 每轮中位 TTFT 是聊天的 7 倍。今天的深度文档讲这个。来源:arXiv 2609.34683
  • vLLM x AgentX(09-08):agent 轨迹中位数 43 轮、142K 输入 token,前缀缓存命中率超 96%;会话粘性路由比负载均衡策略效果更好。来源:vLLM blog
  • llm-d 的 agentic serving 指南:前缀/负载感知路由打底,再叠加分层 KV 卸载、精确前缀缓存路由和 P/D 分离;页面没有给基准数字。来源:llm-d docs
  • Workday 的 Agent Harness、DigitalOcean 的 Agent Data / Agent Learning(10-12 到 10-14):带记忆、护栏、trace、审计的托管 agent 运行时与失败分析服务。只有聚合站转述。来源(二手来源,以原文为准):AI Agents News 周报

学术与课程

  • Agentic Large Language Models(arXiv 2610.13455,10-09):van Duijn、van der Meer、Plaat、van Stein 写的教材式综述,讲 agentic LLM 怎么行动、怎么互相作用,对用户意味着什么。我只读了摘要。来源:arXiv
  • AgenticBBO-Bench(arXiv 2610.12183,10-08):黑盒优化的 agent 基准,覆盖合成函数、超参调优、数据库调优、芯片设计、分子设计。五个领域里 agent 方法都超过直接让 LLM 回答,四个领域超过最强数值优化器;在 Codex harness 里测 7 个 LLM,GPT-6 Astra 和 DeepSeek-V4.1-Flash 在性能/成本前沿上。来源:arXiv
