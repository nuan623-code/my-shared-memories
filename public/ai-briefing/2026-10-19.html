今日头条

1. Schwab 和 JPMorgan 公开说:不让外部 AI Agent 代客户登录、转钱(10-14 至 10-16) Schwab CEO Rick Wurster 对 Bloomberg 说,他们会拦截"用客户账号密码代登录"的外部 Agent,包括 Meta 的 Muse;每周都收到拦截报告,量级是"几十个"。JPMorgan 的 Jamie Dimon 在财报电话会上说不会让"随便什么外部 Agent"进系统,怕"几千个流氓 Agent"。两家都留了口子:JPMorgan 允许部分第三方工具只读查看账户数据;Schwab 说会用 MCP server 让客户自选的模型查余额、做研究,但不能转钱。跟你的关系:你做 Agent 接金融类接口时,"代客户拿密码登录"这条路基本会被堵,要走官方授权接口。今天的深度文档就讲这个。 来源:The Next Web(10-16)、American Banker、Cybernews(10-14,10-16 更新)。American Banker 那篇没写 Schwab 怎么识别 Agent,也没提 MCP;MCP 的说法只出现在 The Next Web。

2. Meta 放出 Muse Spark Open:816B 参数、42B 激活、1M 上下文,权重开放(10-15) 权重放在 Hugging Face、SageMaker、Google Cloud Model Garden、Microsoft Foundry 上,API 有 Baseten、Fireworks、Groq、Together、OpenRouter 等。Meta 自己的数据说它在 agent/tool-use 评测(JobBench、MCP-Atlas)上领先 Kimi K3、GLM 5.3、Qwen3.8,但编码偏弱:Terminal-Bench 2.1 是 76.4,Kimi K3 是 85.0。许可证是 Muse Model License:年收入超 2000 万美元的公司要做 MaaS 得先和 Meta 签协议,产品里要写 "Built with Muse Spark Open",军事和关键基础设施禁用。跑分都是 Meta 自己报的,我没找到独立复现。 来源:The New Stack(10-15)

Agent 技术精选

  • MCP 授权规范(draft)要点。 MCP server 必须实现 Protected Resource Metadata(RFC 9728),客户端必须带 resource 参数(RFC 8707),token 不许放 URL;权限不够返回 403 + insufficient_scope,客户端做 step-up。这套就是银行说的"受限接入"的技术底座。来源:MCP Authorization spec
  • Notion 3.8 "Context for your agents"(10-14)。 把工作区变成给 MCP 兼容 Agent 用的共享上下文层。来源:aitoolly 汇总(二手来源,以原文为准):AIToolly 10-18
  • GitHub Trending 里的几个 agent 工程项目(10-17)。 obra/Superpowers(可组合 skills 流程)、mksglu/context-mode(把工具输出放沙箱,自称省 98% 上下文,没验证)、HKUDS/CLI-Anything(让 Agent 走 CLI 而不是 GUI)。来源:同上(二手)
  • Websites 和银行都在拦 Agent(10-17)。 The Verge 报道网站越来越多地拒绝自主 Agent。这是头条的同一个趋势。来源:AIToolly 转述(二手)
