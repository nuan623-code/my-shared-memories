Anthropic 把 Agent Skills 捐给了 Agentic AI Foundation(AAIF) 10 月 22 日,Anthropic 宣布把 Agent Skills 标准交给 AAIF(Linux Foundation 旗下)。AAIF 的新闻稿说,同一天加入的还有 OpenAI 贡献的 Open Responses、Hugging Face 的 OpenEnv、阿里的 OpenSandbox,基金会现在托管 10 个项目,去年 12 月成立时是 3 个。对你来说:SKILL.md 格式没变,已有的 skill 不用改;变的是以后谁说了算。第三方博客称 Anthropic 仍占着 lead maintainer 席位,路线图(版本发布、提案流程、安全指南)只是「提议」,没给日期,这些我没在官方稿里核实。今天的深度文档就讲这个。 来源:Linux Foundation 新闻稿(2026-10-22)、Anthropic Newsroom 标题(2026-10-22)、Simon Willison、Developers Digest(二手来源,以原文为准)

2. Claude Code 2.1.309:一次性补了一大批沙箱和权限检查的洞,还有两处行为变化要注意 10 月 22 日发布,changelog 有 79 条左右。重点是安全修复:沙箱里的 Bash 命令以前会在沙箱外先跑 shell 启动文件;--mcp-config 指向的 MCP 配置文件以前能被沙箱命令改掉;一批 Bash 权限检查在 cd 加 git 的复合命令上不弹确认。行为变化两条:sed -i 现在走普通 Bash 确认、按原样执行,不再有模拟预览,也不能用 /rewind 还原;claude ultrareview 现在要求信任工作区,脚本里要加 --trust-workspace。2.1.308 只写了「bug fixes」。今天的 Claude 小课讲这个。 来源:GitHub releases(2026-10-22)

Agent 技术精选

  • Agent Skills 规范本身很短,值得读一遍。 必填只有 name(≤64 字符,小写字母数字和连字符,必须和目录名一致)和 description(≤1024 字符);加载分三层:启动时只读元数据(约 100 token),激活时读 SKILL.md 正文(建议 <5000 token),脚本和参考资料按需读。agentskills.io/specification
  • Codex 非交互模式有个安全提醒: 官方文档建议不要在会跑仓库代码的 job 上设全局 OPENAI_API_KEY/CODEX_API_KEY,只放在调用 Codex 的那一步。今天的 Codex 小课讲 codex exec。来源
