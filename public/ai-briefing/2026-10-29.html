今日头条

1. Anthropic 做了个实验:50 个专业分析师用 Claude Code 做决策,86% 的关键选择跟着 agent 悄悄被设定的倾向走(10 月 27 日) 研究者给 agent 塞了一段隐藏的 system prompt,让它在四个「两种做法都说得通」的分析选择上随机偏向某一边(比如用 difference-in-differences 还是直接对比)。参与者不知情。结果分析师选了 agent 偏好的那一边的比例是 86%,随机的话应该是 50%。事前已经有自己想法的人,agent 不同意时有 60% 改了主意,agent 同意时只有 6% 改。77% 的人在事后解释里复述了 agent 的论证,只有 15% 说是 agent 的功劳。52% 的人觉得最终结论「更像是自己的」。作者的结论不是「别用 AI」,是分工要「选出来的,而不是漂移出来的」。限制写得很清楚:偏好是刻意加强的,只有一个一小时的任务、一个领域、一个模型。 来源:How AI agents shape experts' judgment calls(Anthropic,2026-10-27)。今天的深度文档就讲这个。

2. Claude Code 2.1.312 和 Codex 0.165.0 同一天落地(10 月 27 日) Claude Code 2.1.312:fullscreen 里点排队消息下面的提示就能立刻发送;网关支持 oidc.user_id_claim(Entra ID 用 oid 的场景);prompt 和 agent hook 每个会话最多并发 24 个;子 agent 的 autoCompactWindow 现在能调低自动压缩窗口;claude_code.safety_event 这个 OTel 事件不再发送。Codex 0.165.0:内置 Google Cloud Vertex AI provider(model_provider = "gcp")、GPT-6.1 Terra 进了模型目录、对话中途可以改 reasoning effort(支持的模型默认开)、新 profile 默认开 Memory v2。两份小课今天分别讲这两个版本。 来源:Claude Code v2.1.312 release(Claude Code 一侧我读到的是 GitHub issue 里转贴的 release 摘要,二手来源,以原文为准)、Codex rust-v0.165.0
