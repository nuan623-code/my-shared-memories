今日头条

1. Claude Code 2.1.304 / 2.1.305:新增 /auto-mode-setup,Code Review 有了三档深度。 /auto-mode-setup 是一个引导式设置,用来教 auto mode 认识你的环境,现在 Bedrock、Vertex、Foundry 和关了 telemetry 的会话也能用。Code Review 新增 Quick / Standard(默认)/ Deep 三档。2.1.305 还有个会影响升级的改动:allowedMcpServers 不再过滤 managed-mcp.json 里只在 env 用 ${VAR} 的 stdio server,之前被你白名单挡掉的这类 server,升级后会直接加载。想继续挡,用 deniedMcpServers。 来源:Claude Code changelog(页面未标发布日期)

2. Anthropic 官方讲清了反蒸馏防御:90%~99% 的提取数据被挡掉。 这篇是 10 月 12 日发的原文。核心做法有三层:推理内容只给摘要、用分类器拦“让 Claude 吐出完整推理”的请求、对反复尝试的账号限流直至封禁。原文给的数字:分类器上线后,蒸馏方在 Anthropic 平台上拿到的推理 token 低了 10~100 倍。我们前几天只在简报里引过聚合站的转述,今天的深度文档把原文读完了。 来源:Anthropic: distillation defenses(2026-10-12)

官方发布与新功能

  • Claude Code 2.1.305:新增 sandbox.allowNestedUserNamespaces(让沙箱里的命令在 Linux 上能创建 user namespace,跑 Chromium、rootless podman 要用,但文档明说这会绕开沙箱的文件保护);/usage 里每条警告变成一行修复建议,按 f 一键应用。来源:changelog
  • Claude Code 2.1.304:CLAUDE_CODE_AUTO_COMPACT_WINDOW=200k 以前会被悄悄当成 100K,现在 k、M 后缀都认;在 Pro/Max 上,恢复一个久未活动的会话如果会吃掉明显一块 5 小时额度,会先提示。来源:changelog
  • Anthropic 独立评测(10-15):给非营利评测机构 METR 类似员工的访问权限,并在和包括 Hugging Face 在内的其他机构谈。只看到摘要,细节没读。来源:Anthropic Newsroom
  • OpenAI 收购 Orchestra Bio(10-20):官网新闻页列了标题。我没查到交易金额和细节。来源:OpenAI News
  • Gemini 4 Argon 定价(10-13 起 GA):标准档 $2 输入 / $10 输出每百万 token,到 11 月 30 日;12 月 1 日起翻倍到 $4 / $20。这是第三方站点整理的数字,我没对到 Google 官方价格页,下单前请自己核一次。来源:computingforgeeks(二手)
