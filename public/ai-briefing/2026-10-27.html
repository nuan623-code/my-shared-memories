今日头条

1. Anthropic:很多企业 agent 的子 agent 太多了,建议折回一个主循环(10 月 22 日) Anthropic Applied AI 团队写了篇文章,说多个企业客户的经验是:一个靠 skill 和按需加载工具的单 agent,常常比「一堆子 agent」质量更好、延迟更低、成本更低。文章给了三个仍该保留子 agent 的情形(上下文塞爆、需要并行且上下文要干净、选不对工具或指令冲突),以及「先建 eval、合并、当 tool 调用、一次折一个」的迁移步骤,还放了一个 GitHub 迁移套件。文中的数字(一位客户快约 2 倍、Claude Code 的 system prompt 砍掉 80% 以上、工具超过 30–50 个选择会变差)都是 Anthropic 自己给的,没写方法。今天的深度文档讲这篇。 来源:Building agents: When to fold subagents into your main agent loop(2026-10-22)、anthropics/single-agent-loop-kit、The Decoder 报道(二手来源,以原文为准)

2. OpenAI GPT-6.1 Terra:API 价格比上一代砍半,当天进了 Codex(10 月 26 日) Codex changelog 写明:GPT-6.1 Terra 在 ChatGPT Work 和 Codex 里对 Plus、Pro、Business、Enterprise、Edu 开放,不在 Chat 里,不支持阿联酋推理驻留。价格和跑分来自 The Decoder(二手):输入 $2 → $1 每百万 token,输出 $12 → $5;Artificial Analysis 智能指数 48(上一代 42,GPT-6.1 Sol 为 52);Terminal-Bench 4.0 做出 50.3%(此前 21.5%)。这些是第三方转述,我没读到 OpenAI 原文页(请求被拒),价格以官方为准。 来源:Codex changelog 2026-10-26、The Decoder(二手来源,以原文为准)

Agent 技术精选

  • Vals AI:单 agent 对比团队(10 月 9 日)。 50 个全栈 web app,八种配置各跑一次。团队版成本是单 agent 的 1.8–5.1 倍;只有 GPT 6 Sol 的 medium 档团队显著更好(77.6% → 84.9%);Claude Opus 5.5 最便宜配置 91.5% 对最贵 93.2%,成本 $4.08 对 $122 每个 app。作者提醒:一个基准、每种一次。Vals
  • 单循环迁移套件(Anthropic)。 一个 Claude Code skill,按审计、基线、合并、折叠、当 tool、维护六步走;仓库自己标明「不维护、不接受贡献」,部分步骤没在真实模型上跑过。GitHub
  • Claude Code 子 agent 文档。 子 agent 是带 YAML frontmatter 的 Markdown 文件,只有 name 和 description 必填。今天的 Claude 小课讲怎么写。docs
