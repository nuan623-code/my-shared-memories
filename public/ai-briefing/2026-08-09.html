Claude Code 的 auto mode 将成为默认权限模式(公告 08-07,08-14 生效) Anthropic 宣布:自 08-14 起,Pro / Max / Team 计划的新会话默认以 auto mode 运行——每次工具调用先经一个分类器审查,拦截"不可逆、破坏性或指向环境之外"的动作,而不是逐条让人点确认;已固定默认模式的用户不受影响。Enterprise、API、Bedrock、Google Cloud、Microsoft Foundry 暂仍需手动开启,计划约一个月内跟进;Pro/Max/Team 自 08-07 起不再为分类器额外 token 计费。 关键数字(厂商自报):在 1,053 名付费测试者的对照研究中,每个会话把一次权限请求替换成明显危险的命令,人类只拦下 13.6%(143/1,053),auto mode 拦下 89%(937/1,053);人类拦截率从会话初期约 17% 降到 50 次提示后的约 5%。用户批准了 97% 的权限请求,62% 用过 bypass 或"不再询问",25% 的交互会话直接以 bypass 启动。由 Anthropic 委托 Trajectory Labs 做的 720 次间接提示注入测试中,auto mode 下 Claude Fable 5 / Opus 5 / Sonnet 5 零成功。连续 3 次或累计 20 次被拦会退回人工确认。(审批疲劳与分层门控已在 08-07 深度文档中展开,本期不重复。) 来源:Anthropic 博客(2026-08-07)· Developers Digest 08-09
