Agent 技术精选

  • 工具超时后怎么恢复:arXiv 2610.41453 讨论「调用超时了,不知道到底成功没」时 agent 该怎么办,今天的深度文档就讲它。来源:arXiv(2026-10-30)
  • 并行 agent 按需互相问:arXiv 2610.41378 提出 Ask on Demand,并行的 agent 遇到具体信息缺口时向同伴求助,用一个轻量门控判断值不值得问。在 AppWorld 和 WebShop 上评测,摘要只说比各干各的效果好、推理成本比现有信息共享方案低,没给具体数字。来源:arXiv(2026-10-30)
