D0 · 课程页模板（样例）

本页不是正式课程,是每日任务写课时遵循的结构模板。正文文字均为占位示意。

本课目录

每课固定四段:为什么这天学这个 → 概念讲清楚 → 当天能做完的实操 → 验收标准。复杂概念至少给两种讲法(机制拆解 / 类比 / 对比 / 误区澄清任选),有流程或机制的地方配 SVG 图。

为什么这天学这个

占位示意:说明本课在课表里的位置——它依赖前面哪课打下的地基,又为后面哪课铺路。两三段说清楚,让读者知道「跳过这课,后面会卡在哪」。

概念讲清楚

占位示意:先用一段话给出机制拆解,再换一种讲法(类比 / 对比 / 误区澄清)讲同一件事。引用官方文档的事实要带徽章:官方表示官方文档写明的,第三方表示社区来源,本站观点表示本站的判断与编排。

常见误区(样例小节)

占位示意:h3 小节会自动进入左侧目录。误区澄清写「读者以为 X,实际是 Y,判断方法是 Z」。

当天能做完的实操

占位示意:给一串当天 30 分钟内能跑完的步骤,每步可验证:

  1. 第一步做什么,预期看到什么。
  2. 第二步做什么,预期看到什么。
  3. 用下面这段可直接抄的 prompt 试一遍:
这里放读者可以原样粘贴给 Claude Code 的 prompt 样例。
多行时保持排版,右上角有「复制」按钮。

验收标准

占位示意:读者怎么知道自己学会了。写成可自查的清单:

  • 能不看笔记向别人解释本课核心机制。
  • 实操步骤全部跑通,并能解释每步输出。
  • 能回答本课的一道自测题(占位)。
