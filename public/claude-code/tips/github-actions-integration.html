接进 GitHub Actions

把 Claude Code 装进仓库的 CI:在 issue 或 PR 里 @claude 一句话,它就能分析代码、实现功能、修 bug、开 PR。

本页目录

官方 GitHub Actions 集成的核心是 anthropics/claude-code-action@v1 这一个 action:装好 GitHub App、配好 API key secret,它会自动判断是「响应 @claude 提及」还是「按 prompt 直接执行」。

一句话结论

结论 在 Claude Code 终端里跑 /install-github-app,交互式装完 GitHub App、workflow 文件和 ANTHROPIC_API_KEY secret 即接入完成;之后在 issue/PR 评论里 @claude 即可触发。官方整套安装是官方文档写明的快捷路径,前提是你是仓库 admin 且直连 Claude API。

做法步骤

  1. 确认前提:官方安装 GitHub App 和添加 secrets 需要仓库 admin 权限;/install-github-app 快捷方式只对直连 Claude API 的用户可用,走 Amazon Bedrock / Google Cloud 的企业环境要按官方文档手动配 OIDC 与 IAM。
  2. 快速安装:在 Claude Code 终端运行 /install-github-app,按引导安装 Claude GitHub App(要求 Contents、Issues、Pull requests 三项读写权限)、选择 workflow、写入 API key secret。官方v2.1.187 起可以先只装 App 选「Skip for now」,以后再跑一次补配 workflow。
  3. 手动安装(备选):装 github.com/apps/claude → 在仓库 Settings 里加 secret ANTHROPIC_API_KEY → 把官方 examples/claude.yml 拷进 .github/workflows/。官方最小 workflow 长这样: 
    name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]
jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
  4. 验证:在任意 issue 或 PR 评论里发 @claude 解释一下这个 issue 该怎么修。官方注意是 @claude 不是 /claude;action 会根据配置自动检测运行模式——有 prompt 参数就直接执行(自动化模式),没有就响应提及(交互模式)。
  5. 典型工作流:官方三个官方场景:① @claude 提及(上面的基础 workflow);② PR 自动 review——用 pull_request: types: [opened, synchronize] 触发,prompt 里调用 code-review 插件的 skill(通过 plugin_marketplaces + plugins 输入安装),不 @ 也会在每个 PR 上跑;③ 定时任务——schedule: cron 触发加一段 prompt,比如每天 9 点汇总昨日 commit 与 open issues(定时选型对比见 定时任务)。CLI 参数统一从 claude_args 传,如 --max-turns 10、--model、--allowedTools。
  6. 密钥与权限:官方API key 绝不硬编码进 workflow,永远走 GitHub Secrets(${{ secrets.ANTHROPIC_API_KEY }});action 权限收敛到最小;merge 前人工 review Claude 的产出。成本两头算:GitHub Actions 分钟数 + API token 消耗,用 --max-turns、workflow 超时和并发控制兜底。

可直接抄的 prompt

让 Claude Code 帮你写 review workflow(粘贴进本地会话):

给这个仓库加一个 Claude Code GitHub Actions workflow,文件放 .github/workflows/claude.yml:
- 用 anthropics/claude-code-action@v1;
- 触发条件:issue_comment 和 pull_request_review_comment 的 created 事件,响应 @claude 提及;
- API key 从 secrets.ANTHROPIC_API_KEY 读取,workflow 里不允许出现任何明文密钥;
- 在 claude_args 里加 --max-turns 10 防止失控消耗。
