实战 Tip 索引

非线性、按问题检索。每条 Tip 单页自足:问题原句、一句话结论、做法步骤、可直接抄的 prompt、来源与核实日期。

在标题、问题原句、摘要和关键词里搜,空格分隔多个词取交集。

A · 稳定与质量

让它别再「说做完了其实没做完」:验证、回退、review 的方法。

  • 它总说做完了其实没做完—给它能自己跑的验证计划中 · 优先
  • CLAUDE.md 写了它不听—多半是太长计划中 · 优先
  • 大需求先让它面试你产出 SPEC.md计划中
  • 改坏了怎么回退（checkpoint 不是 git）计划中
  • 对抗式 review计划中

B · 并行与效率

多会话、多 agent、worktree:同时推进更多事而不打架。

  • 多session还是多agent能有效提高开发效率计划中
  • worktree 让多会话不打架计划中 · 优先
  • 要改200个文件怎么办计划中
  • 后台跑+手机看进度计划中

C · 设计与素材

UI、生图、模拟器:让做出来的东西不只是能跑,还好看。

  • 如何结合 Claude Design 开发 app UI计划中
  • 如何使用其他生图工具跟 Claude Code 一起开发 app计划中
  • 截图对比让它自判 UI计划中 · 优先
  • iOS 模拟器里跑起来才算做完计划中

D · 成本与上下文

额度、cache、长会话:钱和上下文都花在刀刃上。

  • 哪些操作会让 prompt cache 失效计划中 · 优先
  • 这个月额度怎么烧完的计划中 · 优先
  • 长会话越用越笨计划中
  • MCP 接多了更慢更贵计划中

E · 配置与选型

Skill、Hook、MCP、权限:该用哪个机制,怎么配不折腾。

  • Skill/Hook/MCP/Subagent/Plugin 该用哪个计划中 · 优先
  • 权限：从每步点同意到不打断计划中 · 优先
  • 大仓库 monorepo计划中
  • 出问题先跑这三个计划中

F · 端到端场景

从接手陌生仓库到上架提审:完整场景走一遍。

  • 接手陌生代码库第一天问哪五个问题计划中
  • 从零做 iOS app 到提审计划中
  • 接进 GitHub Actions计划中
  • 定时任务计划中
