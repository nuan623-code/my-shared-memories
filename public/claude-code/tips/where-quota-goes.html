这个月额度怎么烧完的

明明没干多少活,plan 的用量条却见底了——别猜,先跑 /usage 看归因,大头通常不是你以为的那个。

本页目录

额度消耗和「你打了多少字」关系不大,和「每条消息背着多大的上下文、cache 有没有命中」关系极大。这页教你先定位、再止血。

一句话结论

结论 先跑 /usage 看归因 breakdown(按 skill/subagent/plugin/MCP server 的占比,以及 long context、cache miss 标记),再对照五个常见大头:长会话满上下文、cache 过期重算、scheduled tasks、agent teammates、/compact 本身。本站观点多数人的额度是被「一直不 /clear 的长会话」悄悄烧掉的。

做法步骤

  1. 跑 /usage,先看归因再看总量。官方顶部 Session 块是当前会话的 token 统计和本地估算金额(订阅用户这个金额不代表账单,看下面的 plan 用量条即可)。Pro/Max/Team/Enterprise 计划还有一份 breakdown:把最近用量按 skills、subagents、plugins、各 MCP server 拆成百分比,并对占最近用量 10% 以上的行为(如 long context、cache misses)单独标记、附省钱建议;按 d/w 切换最近 24 小时 / 7 天。注意这份数据来自本机会话历史,不含其他设备和 claude.ai 的用量。
  2. 对照官方列出的「长会话烧钱」机制,找自己中了哪几条。官方
    • 长上下文:每条消息都重发全部历史,开了一整天的会话里问一句话,也按整段对话计费(cache 命中按缓存价,但依然在耗)。
    • cache miss:离开超过 cache 存活期(订阅 1 小时;API key、云厂商默认 5 分钟)后,第一条消息全量重算整段上下文。机制见 哪些操作会让 prompt cache 失效。
    • scheduled tasks:定时任务在会话空闲时也按周期触发,每次都带着完整上下文。
    • agent teammates:每个活跃 teammate 各占一个 context window,持续耗 token 直到退出;官方数据是 teammates 跑 plan mode 时 agent teams 约为普通会话 7 倍 token。
    • /compact 本身:压缩要先读完整段对话,大 context 的压缩就是一次大请求;想要干净重开时,/clear 不花钱。
  3. 改习惯止血,收益从高到低。官方
    • 任务间 /clear:切到不相关工作就清;先 /rename 起个名,之后 /resume 能找回来。
    • 模型匹配任务:Sonnet 干日常,Opus 留给复杂架构决策;简单 subagent 任务在配置里指定 model: haiku。
    • 长输出委托 subagent:跑测试、读日志、抓文档这类大输出放子上下文,只回摘要(见 D10 · Subagents)。
    • MCP 只留在用的:/mcp 里关掉闲置 server;gh、aws、gcloud 这类 CLI 比 MCP 更省 context(见 MCP 接多了更慢更贵)。
    • CLAUDE.md 控制在 200 行内,专项流程搬进 skills,按需加载。
    • 简单任务降 effort(/effort)或调低 thinking 预算;thinking token 按输出计费,默认预算可达每请求数万 token。
  4. 团队和 API 用户,用组织级视角对账。官方OpenTelemetry 导出 claude_code.token.usage 和 claude_code.cost.usage,可按用户、按模型进自己的监控栈,任何认证方式都可用;Console(API)用户以 platform.claude.com/usage 为准——本地 /usage 金额按标准列表价估算,不含折扣。

可直接抄的 prompt

帮我做一次 Claude Code 用量体检,目标是找出额度消耗大头并整改:
1. 统计项目根 CLAUDE.md 和 ~/.claude/CLAUDE.md 的行数;超过 200 行时,
   指出哪些段落应该搬进 skills 按需加载;
2. 读取 .mcp.json 及各级 settings 里配置的 MCP server 清单,
   结合本项目实际,标出建议在 /mcp 里关掉的闲置 server;
3. 检查是否配置了 scheduled tasks 或 agent teams 相关设置,
   评估它们的后台消耗;
4. 提醒我自己跑 /usage 和 /context(用户命令,你代跑不了),
   并告诉我分别重点看哪几个字段;
5. 最后输出「立即做 / 本周做」两档的省额度清单。
