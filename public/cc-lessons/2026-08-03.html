第 4 课:Hooks——给 Agent 装确定性护栏

每天一个主题、3-4 条由浅入深的技巧。前三课:CLAUDE.md(07-31)、Plan Mode(08-01)、Subagents(08-02)。 累积库:claude-code-tips.html

1. 概念先行:提示是概率性的,hook 是确定性的

hooks 是在固定事件点自动触发的用户自定义命令,常用事件:PreToolUse(工具执行前,可拦截)、PostToolUse(执行后,善后)、Stop(回合结束)、UserPromptSubmit 等。与 CLAUDE.md 的本质区别:写在记忆里的规则模型可能忘,挂在 hook 上的动作一定发生。

来源:Claude Code 官方文档

2. 最实用的两个起手式

PostToolUse 匹配文件编辑后自动格式化;Stop 时自动跑测试——「写完格式化、改完跑测试」从此不依赖模型自觉。配置在 .claude/settings.json,随 repo 团队共享:

{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{"type": "command", "command": "prettier --write \"$CLAUDE_FILE_PATHS\""}]
    }]
  }
}

来源:SmartScope 实践

3. 安全护栏:PreToolUse 拦截

用 PreToolUse hook 检查 Bash 命令与写入路径,拦下 repo 外写入、危险命令——hook 以非零退出码退出即阻止该次工具调用。这比在 CLAUDE.md 里写「请不要 rm」可靠得多;敏感环境再叠加 --allowedTools 权限白名单双保险。

来源:Claude Code 最佳实践综述

4. 跟上新事件:DirectoryAdded

7 月新增 DirectoryAdded hook,在 /add-dir 挂载新目录后触发——可用来自动注入该目录的说明文档或跑索引脚本。hooks 事件清单随版本更新,建议定期看 What's new。
