第 1 课:CLAUDE.md 项目记忆瘦身术

每天一个主题、3-4 条由浅入深的技巧。本课目标:让 CLAUDE.md 真正被模型「听进去」。 累积库:claude-code-tips.html

1. 建立分层记忆

项目根目录 CLAUDE.md 放团队共享规则(构建命令、代码规范、目录地图);个人偏好放 ~/.claude/CLAUDE.md(全局生效)或项目内 CLAUDE.local.md(不入 git)。会话中输入以 # 开头的消息,可把一条规则当场写入记忆文件,无需打开编辑器:

# 本项目测试一律用 pytest -x,不要用 unittest

来源:Claude Code 官方文档

2. 宁短勿全

社区 2026 年的共识教训:CLAUDE.md 塞得太长,模型会忽略其中一半。只保留「每个会话都必须遵守」的内容,定期无情修剪;项目细节让它现场读代码,不要预写进记忆。判断标准:每一行都问「删掉它,Claude 会犯错吗?」不会就删。

来源:SmartScope:11 条进阶实践

3. 「必须发生」的规则不要靠央求

CLAUDE.md 里写「请永远跑 prettier」是概率性的——模型可能忘。把这类硬规则移到 hooks(如 PostToolUse 自动格式化,后续课程详讲)或权限配置里强制执行;记忆文件只管「倾向与背景」,护栏交给机制。

来源:Claude Code 最佳实践综述

4. 起步用 /init

在存量项目里跑 /init,让 Claude 扫描代码库自动生成 CLAUDE.md 初稿,再按第 2、3 条手工修剪——比从零写快得多,也不容易漏关键构建命令。
