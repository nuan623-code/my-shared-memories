第 3 课:Subagents 与并行分工

每天一个主题、3-4 条由浅入深的技巧。上一课:Plan Mode(08-01)。 累积库:claude-code-tips.html

1. 把「脏活」丢给子代理

大范围检索、翻日志、跑排查这类会产生大量中间输出的活,用 /subtask 交给子代理在独立上下文里做,只把结论带回主会话——主会话上下文保持干净,后续决策质量更高。(注:7 月版本起 /subtask 取代了旧的会话内 subagent 启动方式。)

来源:Claude Code changelog · Tembo:Subagents 2026 实践指南

2. 用 .claude/agents/ 定义专职子代理

在 .claude/agents/*.md 里用 frontmatter 定义自定义子代理:各自的系统提示、工具白名单、模型档位——例如代码评审代理用强模型 + 只读工具,批量跑腿代理用便宜模型。角色即模型档位,贵的智力只花在评审与决策上(呼应 07-31 深度文档的 Planner–Executor 结论)。

来源:Claude Code 官方文档 · Totalum:subagents 生产实践

3. 并行改动用 git worktree

要同时推进多条改动线,别在一个目录里排队:git worktree add ../proj-featureA 为每条线开一个工作树,各跑一个 Claude 实例,互不踩文件,最后正常合并。这是社区公认的多实例并行标准姿势。

git worktree add ../myapp-auth feature/auth
cd ../myapp-auth && claude

来源:SmartScope 进阶实践

4. /fork 分叉会话试第二条思路

7 月新功能:/fork 把当前会话复制成一个后台会话——保留全部上下文,让分身去试激进方案,你在主线继续稳妥推进,两边互不影响。配合 /recap 回顾会话进展,多线并行也不迷路。

来源:Claude Code What's new
